# −80°C Freezer Map

Mobile-first shared freezer map for 400 positions (`L1–L4 / C1–C5 / H1–H5 / D1–D4`).

- Static frontend hosted by GitHub Pages
- Shared data stored in Supabase
- Public read access with Row Level Security
- Protected edits through a database function

The database schema and policies are documented in `supabase/setup.sql`.
